    Shared Control on Curved Surfaces

    Wuhan University of Technology · Apr 2026–Present
    Undergraduate Researcher · Advisor: Prof. Jing Luo

    This project studies how a robot can maintain stable contact with an unknown curved surface while allowing a human operator to safely adjust its motion in real time.

    I developed a surface-corridor framework that combines geometry-aware motion, force regulation, and intent-aware shared control.

    My Contributions

    Surface Geometry
    Designed a trajectory-conditioned corridor from registered point clouds using multiscale robust normal estimation, sign alignment, and two-dimensional smoothing.
    Shared Autonomy
    Developed confidence-weighted intent arbitration that modulates lateral assistance using input amplitude, speed, persistence, directional consistency, and task phase.
    Force Control
    Integrated virtual fixtures and disturbance-observer-enhanced normal admittance, separating autonomous path progression, lateral human correction, and normal-force regulation.

    The system uses ROS with a seven-DoF Sawyer robot, Kinect v2, a wrist force/torque sensor, and a Geomagic Touch device.
